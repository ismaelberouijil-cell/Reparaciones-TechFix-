# Reparaciones-TechFix-


## Contexto del caso de uso
La empresa de asistencia técnica y soporte TechFix va a lanzar el módulo
backend de su nuevo sistema web para la gestión de solicitudes de reparación y
venta de recambios de dispositivos. Para la versión inicial, la dirección necesita
una aplicación en PHP que procese la identificación del cliente, aplique la lógica
de negocio orientada a objetos para calcular presupuestos con impuestos,
gestione el inventario de piezas en el servidor y genere el resumen del
presupuesto en una plantilla HTML de forma completamente segura. Como
desarrollador Back-End, debes construir este módulo e integrar el proyecto en un
repositorio público de GitHub.
